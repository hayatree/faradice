# Security Policy

faradice parses untrusted input files (layouts, technology and configuration files).
Crashes, hangs or excessive memory use triggered by malformed input are treated as bugs.

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/hayatree/faradice/security/advisories/new)
rather than opening a public issue.

## Supported versions

Until 1.0, only the latest released version receives fixes.
