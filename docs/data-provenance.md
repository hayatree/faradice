# Data provenance

Every data file in the repository is either written by hand for faradice, generated by a
program in the repository, or derived from openly licensed public documentation. No file
comes from a proprietary tool, its manuals or its outputs, or from a non-redistributable
PDK.

| Files | Origin | License |
|---|---|---|
| `tech/sky130_uniform.tech.toml`, `tech/sky130_stack.tech.toml` | Layer numbers, heights, thicknesses and dielectric constants read off the process stack description of the public SkyWater SKY130 PDK documentation ([`rules/assumptions`](https://skywater-pdk.readthedocs.io/en/main/rules/assumptions.html), the `main` documentation as read in November 2026; no PDK release is pinned). The values are nominal and partly approximate (see the comments in each file); check them against the PDK version you use | SKY130 documentation: Apache-2.0. The files: MIT OR Apache-2.0 |
| `examples/bus.gds` | Generated by `cargo run -p faradice-gds --example make_bus -- examples/bus.gds` | MIT OR Apache-2.0 |
| `examples/*.toml` | Written for faradice | MIT OR Apache-2.0 |
| `bench/compare/cases/*.toml` | Synthetic structures written for faradice. The SKY130-like cases (L6, C4, C5, V8) take their stack from the same SKY130 documentation as `tech/` | MIT OR Apache-2.0 |
| Test structures in `crates/*/tests/` | Built in code, or synthetic; exact references are analytic solutions | MIT OR Apache-2.0 |
| `crates/faradice-geom/tests/index_props.proptest-regressions` | Seeds recorded by `proptest` | MIT OR Apache-2.0 |
| `gui/vendor/*.patch` | Patches to two upstream crates; see [`gui/vendor/NOTICE.md`](../gui/vendor/NOTICE.md) | The upstream licenses (Apache-2.0, MIT) |

The external solvers used in `bench/compare/` (FasterCap, Palace, Gmsh) are not part of
the repository. Their Docker images download them at pinned versions when built, and
faradice only exchanges files with them; see [`bench/compare/README.md`](../bench/compare/README.md).

If you add a data file, add a row here with its source and license.
